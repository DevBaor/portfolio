# Bao Portfolio

Portfolio React + Vite lấy cảm hứng từ layout trong video tham chiếu.

## Chạy local

```bash
npm install
npm run dev
```

Mở URL Vite hiển thị trong terminal.

## Build production

```bash
npm run build
```

## Chỗ cần thay bằng thông tin thật

- `src/main.jsx`: tên, email, GitHub, LinkedIn, project, skill.
- `.portrait`: thay placeholder bằng ảnh cá nhân nếu muốn.
- `src/styles.css`: màu, font, spacing và animation.

## Ghi chú

Giao diện đã có:
- Dark / Light mode
- Responsive desktop / tablet / mobile
- Smooth scroll
- Scroll reveal animation
- Hero / About / Projects / Expertise / Process / Contact
- Layout grid và typography theo phong cách video
